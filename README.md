# Dawnwick: The Last Word

A phone-first counter-chain roguelike deckbuilder. You collect, build and bet a deck, and the
table answers back: enemies set face-down traps that answer your cards, you set Reactions that
answer theirs, and answers stack into an **Answer Chain** that resolves last-in, first-out.

**Play it in the browser:** https://claude.ai/artifact/8VR11QMwY6GaKuN3hpiHpA

The game was called *Riposte* until v0.14.1. The name changed, but the project folder, save keys
and deck codes still say `riposte` on purpose, so existing saves keep working — see
[`riposte/docs/18-RENAME-DAWNWICK.md`](riposte/docs/18-RENAME-DAWNWICK.md). Don't rename them.

## Where things live

| Path | What it is |
| --- | --- |
| `riposte/` | The game. TypeScript + Vite, Capacitor 7 for iOS and Android. |
| `riposte/src/` | Engine (`src/game/`), card and content data (`src/data/`), UI (`src/ui/`). |
| `riposte/sim/` | Headless tests, the balance simulator, the card lab and the catalog generator. |
| `riposte/docs/` | Design, benchmark, balance and per-version notes. Start with `riposte/README.md`. |
| `riposte/android/`, `riposte/ios/` | Capacitor native shells. |
| `riposte/dist/`, `riposte/dist-single/` | **Checked in on purpose.** `dist/` is the normal web build; `dist-single/index.html` is the one-file build the playable link is published from. They are committed so the current published build is reproducible from the repo without a toolchain, and they are regenerated by `npm run build` / `npm run build:single`. |
| `riposte-play.html`, `riposte-standalone.html` | The single-file builds as published (play = artifact-stripped, standalone = plain). |
| `game-design-prompt.md` | The original brief the project started from. |
| `map-spread/`, `read-the-chain/` | Screenshots from the map and chain UI work. |
| `pixel-art-samples/` | Hi-bit pixel-art experiments: PNGs plus the Python scripts that drew them (`px.py` toolkit). |
| `story-merge-notes.md` | Notes from merging the storyline branch into v0.11. |

## Build and test

Everything runs from the `riposte/` folder:

```sh
cd riposte
npm install
npm test              # rules tests + story checks
npm run build         # typecheck, then the web build into dist/
npm run build:single  # one-file build into dist-single/
npm run dev           # local dev server
```

Other useful scripts: `npm run audit` (card/data sanity checks), `npm run catalog` (regenerate
`docs/CATALOG.md`), and `PROFILE=fresh|career npm run sim -- 100 0 <class>` to run the balance
simulator. Current balance targets and results are in [`riposte/docs/BALANCE.md`](riposte/docs/BALANCE.md).

To publish the playable single-file build:

```sh
cd riposte
npm run build:single
python3 scripts/strip-for-artifact.py dist-single/index.html riposte-play.html
```

Native builds use `npm run cap:ios` / `npm run cap:android` (Xcode or Android Studio required).
